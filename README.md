# Web Scraping Popular Programming Languages

This project was completed as part of the IBM Data Analyst Professional Certificate.

## Tools Used
- Python
- BeautifulSoup
- Pandas
- Requests

## Project Tasks
- Download HTML data from a webpage
- Parse the webpage using BeautifulSoup
- Scrape programming language salary data
- Export the data to a CSV file

## Output
- popular-languages.csv

# web-scraping-project
IBM Data Analyst Certificate project using Python, BeautifulSoup, and Pandas to scrape programming language salary data and export it to CSV.
